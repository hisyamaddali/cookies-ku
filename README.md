# Cookies Ku (Laravel)

## Jalankan di laptop
Salin folder app, database, resources, routes ke proyek Laravel baru,
lalu: php artisan migrate && php artisan serve

## Taruh di internet (Render)
Upload SEMUA isi folder ini ke repo GitHub (termasuk Dockerfile, start.sh, render.yaml),
lalu di render.com: New > Blueprint > pilih repo > Apply.
